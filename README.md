A Chrome extension that turns doomscrolling into a chore.

## How does it work?

After installing, you'll be able to slow down the scrolling speed of any site you like. Difficulty scrolling will passively discourage you from continuing.

Thinking of giving up? Not so fast! You'll have to wait 10 seconds while contemplating your decision before you're able to return to scrolling normally (don't do it!).
